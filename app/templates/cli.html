1. Save your login cookie (once)

PlantXpresso sits behind Life Science Login, so the command line needs your browser's login session:

  1. Install a cookie-export browser extension, e.g. "Get cookies.txt LOCALLY" (Chrome/Edge/Firefox).
  2. On this page, click the extension and export the cookies for this site as cookies.txt.
  3. Copy cookies.txt into the folder where you will download. Keep it private: it works like your password until you log out.

2. Download the files

Run these in a terminal (Linux, or macOS after brew install wget). If the download is interrupted, simply run the second command again — finished files are skipped and partial ones resume.

wget --load-cookies cookies.txt -O {{ stem }}_files.txt "{{ manifest_url }}"
wget --load-cookies cookies.txt -c -x -nH --cut-dirs={{ cut_dirs }} -i {{ stem }}_files.txt
wget --load-cookies cookies.txt -O PlantXpresso_metadata.tsv "{{ metadata_url }}"

Line 1 fetches the list of file links · line 2 downloads them into <Species>/<version>/ folders (-c = resume) · line 3 fetches the full metadata table.
